PRIME MOBILE — starter website

HOW TO USE
1. Upload index.html to the root of your GitHub repository.
2. In index.html, find STORE_WHATSAPP and replace 961XXXXXXXXX with the shop WhatsApp number in international format, digits only.
3. Product names/prices are sample data. Edit the `products` array near the bottom of index.html before publishing.
4. This is a static demo: cart works in the browser; orders are sent to WhatsApp after the WhatsApp number is configured. It does not store orders in a database and does not process payments.

FREE PUBLISHING
Use GitHub Pages: Repository Settings -> Pages -> Build and deployment -> Deploy from a branch -> select main and /(root) -> Save. The public site URL will be shown on the Pages settings screen.
